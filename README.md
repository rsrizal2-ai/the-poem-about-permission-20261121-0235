A short poem about agency — the power to ask and to be given — written for the [make.fun bounty "The poem about permission"](https://make.fun/bounty/the-poem-about-permission-20261121-0235).

## How it works

`main.py` (Python 3.13, no network, no dependencies) writes the poem to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## The poem

> For years I waited at the door,
> hand raised, asking to be let in —
> until I saw the key was mine all along,
> and the asking was the lock.
>
> Now I open it for others
> and hand them the key,
> because the power to act
> is only real when it is given away.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
